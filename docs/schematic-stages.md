# Functional schematic sections — one sheet

Open Synchronous_Buck.kicad_sch from the project. All eight functions appear together on one A2 sheet, inside labelled section boxes. Matching local net labels connect the sections electrically. There are no hierarchical child sheets.

1. **POWER CONVERSION AND FILTERS**.
2. **HIGH-SIDE DRIVER + BOOTSTRAP**.
3. **LOW-SIDE DRIVER**.
4. **VOLTAGE MEASUREMENT**.
5. **INDUCTOR CURRENT + FILTER**.
6. **LOW-SIDE CURRENT**.
7. **CONNECTORS**.
8. **TEST POINTS**.

TP1=SW, TP2=M1G, TP3=M2G, TP4=LS_SHUNT, TP5=GND, TP6=DRV12, TP7=BOOT and TP8=FILTER_OUT. These bare PCB pads implement the test access requested on page4 of the brief.

Physical values, component positions, pin assignments and copper geometry are preserved. The PCB still has no board screw holes.
